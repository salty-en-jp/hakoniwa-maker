# 構想: ジャンルとアセット

追加できるジャンルと、そのジャンルで使うアセットの一覧です。作ったものからチェックを入れていきます。

## 共通アセット

ほぼ全ジャンルで使い回します。カオスに混ぜるときの接着剤になる部品です。

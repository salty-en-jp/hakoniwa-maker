# ジャンルキット

組み込みの部品(ロジックアセット)を組み合わせて作れるジャンルと、その見本のサンプルです。サンプルは「シーン」タブの「サンプルを開く」から開けます。

部品はジャンルごとに分かれていますが、どれも同じ合図(共通語)で話すので、ジャンルをまたいで混ぜられます。たとえばアリーナのおばけにターン制バトルを付けたり、村人に弾を撃たせたりできます。

## 3Dアクション

**サンプル**: コイン集めアスレチック

| 部品 | 役割 |
|---|---|
| プレイヤー操作 | 移動とジャンプ。向いている方向を `data.facing` に書く |
| カメラ追従 | 後ろ上から追いかけるカメラ |
| 往復移動 / 回転 | 動く床、回るギミック |
| 拾えるアイテム / ゴール | コインとゴール |
| ジャンプ台 | 乗ると跳ね上がる |
| 触れたらダメージ | 横から触れるとダメージ、上から踏むと倒せる |
| 落下でアウト | 落ちたらゲームオーバー |

## ADV / ノベル

**サンプル**: はじまりの村

| 部品 | 役割 |
|---|---|
| 調べる・話す | プレイヤーに付ける。近くの話しかけられるものに E キーで `interact` を送り、画面に「E: 名前」と出す |
| 会話 | `interact` を受けたら会話ウィンドウでセリフを出す。1行に「名前: セリフ」。終わると自分に `talked` を送る |

会話の行は、インスペクタの複数行の欄で書けます。会話のあいだは世界が止まります(`pause` をオフにすれば止まりません)。

## ターン制RPG

**サンプル**: はじまりの村

| 部品 | 役割 |
|---|---|
| ターン制バトル | プレイヤーが触れる(`trigger: touch`)か話しかける(`trigger: interact`)と、コマンドバトルが始まる。たたかう・まもる・くすり・にげる |
| HP | バトルでも同じ HP を使う。バトルのダメージは無敵時間を無視する |
| やられたら消える / やられたらゲームオーバー | 勝ち負けの処理 |
| 全滅でクリア | 指定したタグの敵が全部いなくなったらクリア |

## シューター / サバイバル

**サンプル**: おばけアリーナ

| 部品 | 役割 |
|---|---|
| 弾を撃つ | プレイヤーに付ける。キーを押すと、名前で指定したプレハブを向いている方向に出す。2つ付ければ弾とミサイルを撃ち分けられる |
| まっすぐ飛ぶ | 弾。向いている方向に進む |
| 追いかける | 一番近い `target` タグに向かう。敵の追跡にも、ホーミングミサイルにも使える |
| 時間で消える | 弾やエフェクトの寿命 |
| 触れたらダメージ | 弾に付けるときは `destroySelf` をオン、`stompable` をオフ |
| 出現装置 | 一定時間ごとにプレハブを出す |
| 制限時間 | 残り時間を表示。`mode: win` で生き残りクリア、`lose` で時間切れアウト |

## 自分で書くロジック

アリーナの「アリーナの説明」は、組み込みではなくサンプル専用に書いたロジックです。フックを `async` にすると、`await` で待ちながら上から順に書けます。

```js
return {
  async start() {
    game.pause();
    await game.ui.say('アリーナ', 'おばけが わいてくる!');
    const pick = await game.ui.choose(['はじめる', 'もう少し説明して'], 'じゅんびは いい?');
    if (pick === 1) await game.ui.say('アリーナ', 'たまは 1、ミサイルは 2 ダメージ。');
    game.resume();
  }
};
```

# 親子関係とプレハブ

## 親子関係

オブジェクトは、他のオブジェクトの「子」にできます。子は親にくっついて、一緒に動き、回り、大きさが変わり、消えます。

- **親を決める**: 子にしたいものを選び、インスペクタの「親」で親を選びます。見た目の位置は変わりません
- **子を足す**: 親を選んで、インスペクタの「子を足す」を押します
- **一覧**: 「シーン」タブのオブジェクト一覧では、子が親の下に字下げされて並びます
- **複製と削除**: 子孫ごとまとめて行われます

### 位置・回転・大きさは「親から見た値」

子のトランスフォームは、親の位置・回転・大きさを基準にした値です。たとえば親が横に2倍に引き伸ばされていると、子も横に2倍に見えます。

形をいびつにしたくないときは、形が **空** のオブジェクトを親にするのがおすすめです。空は見えない「まとめ役」で、大きさ 1 のまま子をまとめられます。サンプルの風車は、空の「風車」の下に柱・屋根・回転軸があり、回転軸の下に羽根があります。回転軸を回すと羽根が一緒に回ります。

### 再生中の親子

- 当たり判定は、そのオブジェクト自身の形で取ります。子の形は親の判定に含まれません
- 子は親にくっついて動くので、物理が「動く」でも重力では落ちません
- 同じ親子の中(先祖と子孫)どうしは、触れても `onCollide` が呼ばれません
- 親が `destroy()` すると子も消えます

ロジックからは次のように行き来できます。

```js
self.parent              // 親の self(なければ null)
self.children            // 子の self の配列
self.findChild('右目')   // 子孫から名前で探す
self.worldPosition()     // 親子の影響を全部足した本当の位置

// 子から親に合図を送る
self.parent.send('damage', 1, self);
```

## プレハブ

親子でまとめたものを「型」として保存し、何個でも置けるようにする仕組みです。

### 作る

1. まとめたいものの一番上の親を選びます
2. インスペクタの「プレハブ」にある「プレハブにする」を押します

選んだものは、そのプレハブのインスタンス(型から作られたもの)になります。

### 置く

「シーン」タブの「プレハブ」の一覧で「置く」を押すと、視点の中心あたりに置かれます。ロジックからは `game.spawn('プレハブの名前', { x, y, z })` で出せます。

### 直して、全部にそろえる

インスタンスはふつうのオブジェクトと同じように自由に編集できます。型と違うところがあると、インスペクタに「変更あり」と出ます。

| ボタン | すること |
|---|---|
| プレハブに反映 | このインスタンスの今の形で型を上書きし、同じプレハブの他のインスタンスも全部そろえる |
| 元に戻す | このインスタンスを型どおりに戻す |
| つながりを切る | ふつうのオブジェクトに戻す。以後、反映の影響を受けない |

インスタンスごとに違ってよいのは、一番上の親の **名前・位置・回転・大きさ・親** だけです。それ以外(色、子の配置、ロジックやそのパラメータ)は、反映するとそろいます。1つだけ違う動きにしたいときは、つながりを切ってください。

### プレハブの名前と削除

「シーン」タブのプレハブ一覧で名前を変えられます。削除しても、置いてあるものは残ります(つながりが切れるだけです)。

## 保存の形

```js
project.prefabs = [
  {
    id: 'p1',
    name: 'ちびロボ',
    objects: [            // 型の中身。先頭が一番上の親
      { id: 'n1', parent: null, ... },
      { id: 'n2', parent: 'n1', ... }
    ]
  }
];

// シーンに置いたもの
{ id: 'o101', prefab: 'p1', prefabNode: 'n1', parent: null, ... }   // インスタンスの一番上
{ id: 'o102', prefabNode: 'n2', parent: 'o101', ... }              // その子
```

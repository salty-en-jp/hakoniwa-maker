# 合図と共通語

合図(メッセージ)は、ロジックどうしがお互いの中身を知らなくても連携できるようにする仕組みです。

たとえば「触れたらダメージ」は、相手に `damage` という合図を送るだけです。相手が HP を持っているのか、ロボの装甲なのか、ターン制の敵なのかは知りません。受け取る側も、誰に何をされたかを気にせず `damage` に反応するだけです。だから、まったく別のジャンルの部品どうしでも混ぜて使えます。

## 使い方

```js
// 受け取る: 名前と、届いたときに呼ばれる関数
self.on('damage', (amount, from) => {
  // amount は送り手が渡した値、from は送り手(省略されることもある)
});

// 送る: 相手の send を呼ぶ。3つ目に自分を渡すと、相手が「誰から」を知れる
other.send('damage', 2, self);

// 自分に送る: 同じオブジェクトに付いた他のロジックへの連絡に使う
self.send('died');

// 全員に送る。3つ目にタグを渡すと、そのタグの全員だけに送る
game.broadcast('alarm', { x: 1 }, 'enemy');
```

- `self.on` は、ロジックの一番外側(`return` より前)か `start()` の中で呼びます
- 同じ名前の合図を、同じオブジェクトの複数のロジックが受け取れます。付けた順に呼ばれます
- 合図は送ったその場で届きます(次のフレームまで待ちません)
- 合図の中で合図を送るのは自由です。ただし 32 段を超えて続くと、止まらないループとみなして止めます
- 受け取った関数の中でエラーが出ても、ほかの受け取り手には届き続けます。エラーは画面下のログに出ます
- 消えたオブジェクトには届きません

## 共通語

部品どうしが混ぜられるように、よく使う合図の名前と中身をここで決めておきます。新しい部品を作るときは、なるべくこの名前を使ってください。

| 合図 | data | 意味 | 送る部品 | 受け取る部品 |
|---|---|---|---|---|
| `damage` | ダメージ量(数値、省略時 1)か `{ amount, pierce }` | ダメージを受けた。`pierce: true` は無敵時間を無視する | 触れたらダメージ、ターン制バトル | HP |
| `heal` | 回復量(数値、省略時 1) | 回復した | 回復アイテム、ターン制バトル | HP |
| `died` | とどめを刺した相手 | HP が 0 になった(自分自身に届く) | HP | やられたら消える、やられたらゲームオーバー |
| `hpChanged` | `{ hp, max }` | HP が変わった(自分自身に届く。表示用) | HP | (表示を作るときに使う) |
| `interact` | 話しかけた相手 | 調べられた・話しかけられた | 調べる・話す | 会話、ターン制バトル(`trigger: interact`) |
| `talked` | 話しかけた相手 | 会話が終わった(自分自身に届く) | 会話 | ターン制バトル(`trigger: talked`) |

### これから足す予定の共通語

| 合図 | data | 意味 |
|---|---|---|
| `pickup` | アイテムの情報 | アイテムを拾った |
| `use` | 使ったもの | 使われた |
| `equip` | 装備の情報 | 装備した |
| `stun` | 秒数 | 怯んだ・気絶した |
| `trigger` | 任意 | スイッチやイベントが作動した |

### `data`(共有メモ)

合図とは別に、同じオブジェクトに付いたロジックどうしは `self.data` で値を共有できます。HP は `data.hp` と `data.maxHp`、プレイヤー操作は `data.facing`(向いている方向)を書きます。

## 組み合わせの例

**話しかけたらバトル**: 会話 + ターン制バトル(`trigger: talked`)にすると、話し終わったところでバトルが始まります。

**敵**: 往復移動 + 触れたらダメージ + HP(max 1)+ やられたら消える

1. プレイヤーが横から触れる → 敵の「触れたらダメージ」がプレイヤーに `damage` を送る
2. プレイヤーの「HP」が減る。0 になると、プレイヤー自身に `died` を送る
3. プレイヤーの「やられたらゲームオーバー」が `died` を受けて `game.lose()` を呼ぶ

**踏みつけ**: プレイヤーが上から落ちてきたときは、敵の「触れたらダメージ」が自分自身に `damage` を送る → 敵の「HP」が 0 になり `died` → 「やられたら消える」で消える

「やられたら消える」を「やられたら爆発する」に差し替えれば、ほかの部品を一切変えずに倒れ方だけを変えられます。
